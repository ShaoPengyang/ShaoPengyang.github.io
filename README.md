# Pengyang Shao — Academic Homepage

A lightweight, dependency-free single-page website.

## Local preview

From the repository root, use VS Code Live Server or run any static file server, for example:

```powershell
py -m http.server 8000
```

Then open <http://localhost:8000>.

The website consists of `index.html`, `assets/site.css`, and `assets/site.js`. Academic files and images live in `files/` and `images/`.
